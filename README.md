# Assessment Management System
A C++ project to manage student assessments, including grades and subjects, with CSV file I/O for storing results.

## How to Build
Run: `g++ -std=c++23 main.cpp School.cpp Student.cpp -o main.exe`

## Files
- main.cpp: Entry point of the program
- School.h, School.cpp: Manages students and subjects
- Student.h, Student.cpp: Represents a student with grades
- Subjects.h: Represents subjects with names and short names
